**Calibration (production hybrid model).** Expected calibration error (lower = better): the live form + Dixon-Coles model scores **0.025** — already well-calibrated. Leak-free recalibration (`hybrid_form_dc_cal`, temperature scaling fit on prior editions only) does not help (0.026); it is *evaluated, not applied* — the production forecast stays uncalibrated. An optimistic in-sample isotonic ceiling reaches 0.019, so the residual miscalibration is real but too small to learn reliably from five tournaments.
