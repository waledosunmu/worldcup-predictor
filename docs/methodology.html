How this works

Every prediction comes from a pipeline that is fully reproducible from public data:

  1. Ratings. We replay all 49,520 international matches since 1872 through a replication of the World Football Elo system (match-importance K-factors, margin-of-victory multipliers, +100 home advantage). Our ratings correlate 0.986 with the official eloratings.net figures across the 48 finalists.
  2. Goals model. Elo difference (plus a recent-form differential) maps to expected goals, fit by maximum likelihood on 17,969 competitive internationals since 1998, with a Dixon-Coles correction for low-scoring scorelines. This form + Dixon-Coles hybrid is the live model; it beats the Elo-only baseline out-of-sample (see Model variants). Pass --model v0 for the baseline.
  3. Tournament simulation. We simulate the full 2026 format 100,000 times — 12 groups with FIFA's 2026 tiebreakers (head-to-head first, FIFA-ranking last), the eight best third-placed teams into the new Round of 32, extra time at 0.33× expected goals, penalties as a coin flip.
  4. Market benchmark. A bookmaker-consensus forecast (constant-overround removal per book, geometric-mean pooling) from 4 books on the outright market and up to 49 books per match.

Are the probabilities honest? Calibration

A forecast is calibrated if the things it calls 70%-likely happen about 70% of the time. Across the 320 backtest matches the live form + Dixon-Coles model's expected calibration error is 0.025 (0 = perfect) — it is already well-calibrated (the Dixon-Coles term, which corrects low-scoring draws, is part of why). Each dot below bins the model's predictions by confidence and plots them against how often the outcome actually happened; the closer to the diagonal, the better.

We tested recalibrating the model (temperature scaling, learned only from earlier tournaments): out-of-sample it does not help (0.026 vs 0.025), so the published forecast is left uncalibrated — this panel is a measurement, not an adjustment. An optimistic in-sample ceiling reaches 0.019, so the small residual is real but can't be learned reliably from five tournaments.

Model variants

Each extension is implemented and backtested point-in-time over the same 320 matches (lower is better). The Dixon-Coles correction adjusts low-scoring scorelines; the covariate model adds recent form to the Elo signal. The combined form + Dixon-Coles hybrid wins on every metric — so it is now the live production model (log loss 0.963 vs v0's 0.972). v0 stays selectable as the baseline.

Honest caveats

  • Elo sees results only — no squad values, injuries, or lineup news. That is the main reason the model diverges from the market on teams like Argentina (model higher) and Portugal (market higher).
  • Third-place bracket slots use constraint-satisfying assignment, not FIFA's exact 495-combination allocation table.
  • The conduct-score (cards) tiebreaker is not simulated; the FIFA-ranking tiebreaker is proxied by Elo.
  • No published model has ever been validated on a 48-team World Cup — including this one. 2026 is new territory for everybody.
